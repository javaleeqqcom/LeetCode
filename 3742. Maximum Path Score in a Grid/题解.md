# 1.思路
- 使用动态规划，定义三维数组 `dp[i][j][c]` 表示从起点 `(0,0)` 走到格子 `(i,j)`，且总成本恰好为 `c` 时，能获得的最大得分。由于只能向右或向下移动，状态转移只依赖上方或左方格子。
- 初始时所有状态设为 `-INF`（一个足够小的负数，表示不可达）。起点 `(0,0)` 的值为 0，成本 0 时得分为 0，故 `dp[0][0][0] = 0`。
- 根据格子 `grid[i][j]` 的值分情况转移：
  - 若值为 0：不消耗成本，也不增加得分。直接继承上方或左方相同成本的得分：`dp[i][j][c] = max(dp[i-1][j][c], dp[i][j-1][c])`。
  - 若值为 1 或 2：消耗 1 成本，增加 score = grid[i][j] 分。因此从上方或左方的成本 `c-1` 转移过来：`dp[i][j][c] = max(dp[i-1][j][c-1], dp[i][j-1][c-1]) + grid[i][j]`，其中 `c >= 1`。
- 最终答案为 `max(dp[m-1][n-1][c])` 对所有 `0 <= c <= k` 取最大值。若最大值为负（即所有状态不可达），则返回 -1。

# 2.解题过程
- 利用 `numpy` 数组实现三维 DP，其向量化操作可以高效处理整层或整段的更新。
- 对于当前格子 `(i,j)`，若值为 0，直接使用 `np.maximum` 将上/左的整层（k+1 种成本）拷贝过来。
- 若值非 0，则通过切片将上/左的 `dp[:, :, :-1]`（即成本 0 到 k-1）加上当前得分后，赋值给当前格子的 `dp[:, :, 1:]`（成本 1 到 k），同样使用 `np.maximum` 取最优。
- 遍历所有格子后，从终点格子的成本维度取最大值并转为 Python 标量，若为负数则返回 -1。

# 3.复杂度
- **时间复杂度**：`O(m * n * k)`，因为每个格子需要对所有 `k+1` 种成本进行常数次更新。实际由于 numpy 向量化，常数较小。
- **空间复杂度**：`O(m * n * k)`，存储整个 DP 表。若使用滚动数组优化可降至 `O(n * k)`，但本题数据范围（m,n ≤ 200，k ≤ 1000）下三维数组约 40M 个 `int32`（约 160MB），在 Python 中可能较大，但通常可接受。

# 4.代码
```python
import numpy as np
from typing import List

INF = (1 << 31) - 1

class Solution:
    def maxPathScore(self, grid: List[List[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        dp = -INF * np.ones((m, n, k + 1), dtype=np.int32)
        dp[0, 0, 0] = 0   # 起点成本0得分0

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 0:
                    # 成本不变，得分不变
                    if i > 0:
                        dp[i, j, :] = np.maximum(dp[i, j, :], dp[i - 1, j, :])
                    if j > 0:
                        dp[i, j, :] = np.maximum(dp[i, j, :], dp[i, j - 1, :])
                else:
                    # 成本+1，得分+grid[i][j]
                    if i > 0:
                        dp[i, j, 1:] = np.maximum(dp[i, j, 1:], grid[i][j] + dp[i - 1, j, :-1])
                    if j > 0:
                        dp[i, j, 1:] = np.maximum(dp[i, j, 1:], grid[i][j] + dp[i, j - 1, :-1])

        res = np.max(dp[m - 1, n - 1, :])
        return max(-1, int(res))   # 若所有状态不可达则返回 -1
```
