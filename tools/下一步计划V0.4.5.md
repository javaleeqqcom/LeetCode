#### 2️⃣ 新增格式检测函数（单/多线程共用）

```python
def _detect_input_format(input_params: Any) -> Literal['args', 'kwargs']:
    """
    检测 input_params 是元组还是字典格式
    返回 'args' 或 'kwargs' 用于选择 caller 函数
    """
    if isinstance(input_params, tuple):
        return 'args'
    elif isinstance(input_params, dict):
        return 'kwargs'
    else:
        # 单个值的情况，视为 args 的单元素元组
        return 'args'


def _select_caller(input_params: Any) -> Callable:
    """
    根据 input_params 格式选择对应的 caller 函数
    需要从 args_parser_caller 导入
    """
    from .args_parser_caller import main_caller_args, main_caller_kwargs
    
    format_type = _detect_input_format(input_params)
    return main_caller_args if format_type == 'args' else main_caller_kwargs
```

#### 3️⃣ 重构 `_execute_single_case`（单/多线程共用核心）

```python
def _execute_single_case(
    caller: Callable,
    instance: object,
    main_method: str,
    case: _CASE_TYPE,
    exchange_code: str = ""
) -> Tuple[_CASE_TYPE, List[str]]:
    """
    通用执行函数，兼容元组和字典格式
    
    Args:
        caller: main_caller_args 或 main_caller_kwargs
        instance: Solution 实例
        main_method: 主方法名
        case: 测试用例 {"input": ..., "expected": ...}
        exchange_code: 交换代码（用于动态方法）
    
    Returns:
        (result_case, errors)
    """
    errors = []
    result_case = case.copy()
    
    try:
        # 使用 caller 执行，而非直接调用 the_fun
        output = caller(instance, main_method, case['input'])
        result_case['output'] = output
    except Exception as e:
        errors.append(f"Execution Error: {str(e)}")
        result_case['output'] = None
    
    # 验证结果（如果有 expected）
    if 'expected' in case and case['expected'] is not None:
        if not _verify_output(case['expected'], result_case.get('output')):
            errors.append(f"WA: expected {case['expected']}, got {result_case.get('output')}")
    
    return result_case, errors
```

#### 4️⃣ 修改 `run()` 方法（单线程入口）

```python
def run(
    self,
    test_cases: List[_CASE_TYPE],
    main_method: str = "main",
    exchange_code: str = "",
    timeout: int = None
) -> List[Tuple[_CASE_TYPE, List[str]]]:
    """
    单线程运行所有测试用例
    """
    if not test_cases:
        return []
    
    # ========== 新增：检测格式并选择 caller ==========
    # 只检测首个样例，假设所有样例格式一致
    first_input = test_cases[0].get('input')
    caller = _select_caller(first_input)
    
    # ========== 可选：添加格式混用校验 ==========
    first_format = _detect_input_format(first_input)
    for i, case in enumerate(test_cases[1:], 1):
        if _detect_input_format(case.get('input')) != first_format:
            raise ValueError(
                f"测试用例格式混用：case[0] 为 {first_format}，"
                f"case[{i}] 为 {_detect_input_format(case.get('input'))}"
            )
    
    # ========== 执行所有用例 ==========
    results = []
    for case in test_cases:
        result, errors = _execute_single_case(
            caller=caller,
            instance=self.instance,
            main_method=main_method,
            case=case,
            exchange_code=exchange_code
        )
        results.append((result, errors))
    
    return results
```

#### 5️⃣ 修改 `_execute_in_interpreter_worker`（多线程 worker）

```python
def _execute_in_interpreter_worker(
    code: str,
    test_cases: List[_CASE_TYPE],
    main_method: str,
    exchange_code: str,
    pre_code: str
) -> List[Tuple[_CASE_TYPE, List[str]]]:
    """
    子解释器 worker 函数（多线程使用）
    """
    # 在子解释器中执行 pre_code（包含 args_parser_caller.py）
    exec(pre_code, _GLOBAL_NAMESPACE)
    
    # 执行用户代码
    exec(code, _GLOBAL_NAMESPACE)
    
    # 获取 instance
    instance = _GLOBAL_NAMESPACE.get('Solution')()
    
    # ========== 检测格式并选择 caller（与单线程一致）==========
    first_input = test_cases[0].get('input') if test_cases else None
    caller = _select_caller(first_input) if first_input else main_caller_args
    
    # 执行所有用例
    results = []
    for case in test_cases:
        result, errors = _execute_single_case(
            caller=caller,
            instance=instance,
            main_method=main_method,
            case=case,
            exchange_code=exchange_code
        )
        results.append((result, errors))
    
    return results
```

def read_test_case(file_path: Union[str, Path]) -> List[_CASE_TYPE]:
    """
    读取测试用例文件，保留自动包装能力
    """
    with open(file_path, 'r', encoding='utf-8') as f:
        cases = json.load(f)
    
    result = []
    for i, case in enumerate(cases):
        # 自动包装：无 input 键时包装
        if 'input' not in case:
            case = {'input': case}
        
        # 添加 cid（如果不存在）
        if 'cid' not in case:
            case['cid'] = i
        
        result.append(case)
    
    return result

### 四、单/多线程共用逻辑总结

| 功能 | 单线程位置 | 多线程位置 | 是否共用 |
|------|-----------|-----------|---------|
| 格式检测 `_detect_input_format` | `run()` 调用 | `_execute_in_interpreter_worker()` 调用 | ✅ 共用函数 |
| Caller 选择 `_select_caller` | `run()` 调用 | `_execute_in_interpreter_worker()` 调用 | ✅ 共用函数 |
| 执行逻辑 `_execute_single_case` | `run()` 循环调用 | `_execute_in_interpreter_worker()` 循环调用 | ✅ 共用函数 |
| 格式混用校验 | `run()` 中 | 可选添加 | ⚠️ 单线程专用 |
| pre_code 构建 | `__init__` | `__init__` | ✅ 共用 |

### 五、风险与注意事项

| 风险点 | 描述 | 解决方案 |
|--------|------|---------|
| **格式混用** | 同一批 test_cases 中元组/字典混用 | `run()` 开头添加校验，发现混用立即报错 |
| **空 test_cases** | 无测试用例时 `_select_caller` 会出错 | 添加 `if not test_cases: return []` 前置检查 |
| **子解释器导入** | `args_parser_caller.py` 在子解释器中可能导入失败 | 将内容直接拼接到 `pre_code` 中，而非 import |
| **cid 冲突** | `read_test_case` 和生成器都生成 cid | 统一逻辑：读取时生成，生成器中也生成，以实际数据为准 |
| **expected vs output** | 旧用例用 `expected`，新规范用 `output` | 兼容两种键名，在验证时统一处理 |
