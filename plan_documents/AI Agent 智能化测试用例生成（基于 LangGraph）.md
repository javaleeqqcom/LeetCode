
6. **AI Agent 智能化测试用例生成（基于 LangGraph）**
   - 当前框架已支持手动编写测试用例和暴力算法生成。下一步将引入 **AI Agent**，实现从题目描述到可执行测试代码的全自动生成，降低人工编写用例的成本。
   - 工作流设计（LangGraph 状态机）
```
题目描述/学生代码 → 类型分类 → 选择提示词模板 → 生成测试代码 → 沙箱执行 → 验证
                          ↑                                        │
                          └────────── 失败 + 错误反馈 ──────────────┘
```
   - 核心功能
     - **类型智能分类**：通过文本分析或轻量级模型（如 GPT-3.5）判断题目涉及的输入输出类型（基础类型、链表、二叉树、多方法调用等），自动选择合适的提示词模板。
     - **测试代码生成**：调用大模型（GPT-4/Claude）生成符合框架规范的测试样例生成代码（`test_cases_generator.py`），并可选生成类型转换代码（`conversion.py`）。
     - **沙箱安全执行**：自动生成代码文件后，在隔离环境（受限子进程）中执行，检测是否包含危险操作（文件读写、注册表、系统命令等），非管理员权限运行。
     - **错误自愈循环**：若执行失败，将错误信息和原始代码拼接到新的提示词中，调用更高能力模型（如 GPT-4 → GPT-4o）重新生成，最多重试 `max_request` 次。成功时输出测试用例 JSON 文件并通知用户。

   - 实现路径
```
| 阶段 | 任务 | 状态 |
|------|------|------|
| Phase 1 | 基于 LangGraph 搭建基础状态机（分类→生成→执行→重试） | 🔲 计划中 |
| Phase 2 | 实现类型分类器（正则 + 小模型混合） | 🔲 计划中 |
| Phase 3 | 设计多套提示词模板（链表/树/基础/多方法） | 🔲 计划中 |
| Phase 4 | 集成沙箱执行环境（受限子进程 + 依赖扫描） | 🔲 计划中 |
| Phase 5 | 错误反馈循环 + 模型升级策略 | 🔲 计划中 |
| Phase 6 | 命令行工具 `ai-gen-cases` 封装 | 🔲 计划中 |
```

   - 预期效果
     - **零手工编写**：用户只需提供题目描述或代码，AI 自动生成完整测试套件。
     - **自适应重试**：失败用例自动修正，直至成功或达到上限。
     - **类型精准**：区分链表环检测、二叉树重复引用等复杂场景，生成正确转换代码。

   - 其他优化项（保持原有计划）
     - **极小化预定义代码**：智能筛选学生代码实际使用的特殊类型。
     - **VS Code 插件集成**：一键运行测试，结果展示在侧边栏。
