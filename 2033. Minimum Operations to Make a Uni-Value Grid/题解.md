# 2033. 获取单值网格的最小操作数

## 1. 思路

### 1.1 序列化
显然，结果与 `grid` 的矩阵形状无关，只需将所有元素展平为一维数组 `L`。后续操作只与数值大小有关。

### 1.2 同余检查
要使所有元素通过加减 `x` 变得相等，任意两个元素的差必须是 `x` 的倍数，否则不可能。  
因此，取 `base = grid[0][0]`，检查每个元素 `v` 是否满足 `(v - base) % x == 0`，即所有元素模 `x` 同余。若存在不满足的，直接返回 `-1`。

\[
\forall v \in \text{grid},\quad (v - \text{base}) \bmod x = 0 \quad \Longleftrightarrow \quad v \equiv \text{base} \pmod{x}
\]

### 1.3 中位数与一阶矩的关系
记 `L = [a_0, a_1, ..., a_{n-1}]`。在满足同余的前提下，问题转化为：
> 找到目标值 `t`，使得 `sum(|a_i - t|)` 最小。

由绝对值求和的性质，当 `t` 取 `L` 的中位数时，该和最小（一阶矩最小化）。中位数定义为：
- 若数组长度为奇数，取中间那个数；
- 若长度为偶数，取最中间两个数之间的任意值，此时绝对差之和为常数（最小值）。

由于所有数模 `x` 同余，设排序后数组为 `a_0 ≤ a_1 ≤ … ≤ a_{n-1}`。当 `n` 为偶数时，取任意 `t ∈ [a_{n/2-1}, a_{n/2}]`，则：
\[
\sum |a_i - t| = \sum_{i=0}^{n/2-1} (t - a_i) + \sum_{i=n/2}^{n-1} (a_i - t) = \text{常数}
\]
因为左右两部分中 `t` 的系数 `-(n/2) + (n/2) = 0`，所以和与 `t` 无关。  
因此我们可以直接取 `t = a_{n/2}` 或 `a_{n/2-1}`（代码中 `np.median(L)` 得到的是两个中间数的平均值，如 `2.5`），代入 `t` 后计算 `sum(|a_i - t|)`，结果一定为 `x` 的整数倍，所以整除 `x` 后即为最少操作次数。

## 2. 解题过程

1. 将 `grid` 展平为一维数组 `L`。
2. 检查所有元素是否模 `x` 同余（`L % x` 是否全相等）。若否，返回 `-1`。
3. 计算 `L` 的中位数 `m`（使用 `np.median` 或手动排序取中间位置）。
4. 计算 `sum(|L - m|) // x` 作为答案并返回。

## 3. 复杂度

- **时间复杂度**：`O(mn log(mn))`，主要来自排序（`np.median` 内部会排序）。
- **空间复杂度**：`O(mn)`，用于存储一维数组。

## 4. Code

```python
import numpy as np
from typing import List

class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        L = np.array(grid, dtype=np.int32).flatten()
        # 同余检查
        R = L % x
        if not all(R == R[0]):
            return -1  # 非同余，必定无解
        # 求中位数（内部排序）
        m = np.median(L)
        # 总操作次数
        return int(np.abs(L - m).sum() // x)
```
